# 4ETHR — Three minds. One digital frequency.

Standalone frontend portfolio built with React, JavaScript, CSS, HTML, and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Create a production build

```bash
npm run build
```

The team portraits live in `public/assets/`, and team content is maintained in
`src/data/team.js`.

## Deploy to Vercel

This project includes `vercel.json` configured for Vite:

- **Build command:** `npm run build`
- **Output directory:** `dist/public`
- **Framework preset:** Vite

Import the repository into Vercel and deploy with the default project settings.
If configuring it manually, use the same build command and output directory.
